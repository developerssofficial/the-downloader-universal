# The Downloader (Universal Pro)

A powerful, all-in-one local media downloader for **YouTube, Facebook, Instagram, TikTok, Twitter/X, Pinterest & Reddit**.

## Features:
- 🔴 **YouTube:** 4K UHD, 1080p Full HD, 720p HD, 360p, MP3 320kbps Studio Audio.
- 🔵 **Facebook:** Reels, Watch Videos, Public Posts in HD MP4 & MP3.
- 🟣 **Instagram:** Reels, Stories, Videos & Full-Resolution Original Photos.
- 🎵 **TikTok:** HD Videos (without watermark) & Audio.
- 𝕏 **Twitter / X:** High Quality Videos & Images.
- 🚀 **100% Native:** Zero third-party web blockers, no DNS issues, saves directly to your browser & PC.

## How to Run:
Double-click `Start_App.bat` or run:
```bash
python app.py
```
Open **`http://localhost:7860`** in any browser!
